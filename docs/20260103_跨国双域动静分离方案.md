### 🌐 最终架构概览：跨国双域动静分离方案
*   **主控站（Fallback Domain）**：`hiyinni.cn` (托管于 Cloudflare)
*   **接入站（Custom Hostname）**：`hiyinni.com` (托管于 腾讯云 DNSPod)
*   **源站（Origin）**：AWS S3 (雅加达区域 `ap-southeast-3`)

---

### 第一阶段：SaaS 回源与证书打通
**目标**：解决 `cdn.hiyinni.com` 的证书一直“验证中”及访问超时问题。
1.  **DCV 委派**：在腾讯云配置 `_acme-challenge.cdn` 的 **CNAME** 指向 Cloudflare 提供的 `dcv.cloudflare.com` 地址。实现证书**一劳永逸自动续期**。
2.  **回源配置**：在 Cloudflare 中将 `cdn.hiyinni.com` 设置为自定义主机名，源服务器指向 `cdn-s3.hiyinni.cn`。
3.  **Cloud Connector（核心）**：配置 Cloud Connector，将匹配条件设为 `主机名 等于 cdn.hiyinni.com`，回源 URL 填入 S3 的完整域名。
    *   **关键点**：它自动解决了 S3 要求的 `Host` 标头重写和 SSL 握手问题。

---

### 第二阶段：中国区优选 IP 自动化
**目标**：解决 Cloudflare 默认 IP 在国内访问慢、甚至连接中断的问题。
1.  **工具选择**：使用 `ymyuuu/BestDomain` 配套 GitHub Actions。
2.  **代码微调**：修改脚本 `bestdomain.py`，将原本修改 CF 解析的逻辑改为通过 **DNSPod API** 修改腾讯云记录。
3.  **变量配置**：设置 `DNSPOD_ID`、`DNSPOD_TOKEN`、`DOMAINS`、`SUB_DOMAINS` 等 Secrets。
4.  **效果**：GitHub 每小时自动筛选出国内最快的 Cloudflare IP，并实时更新到腾讯云的 **“默认（境内）”** 解析线路上。

---

### 第三阶段：全球分线路解析（智能导航）
**目标**：解决“国内快了，印尼反而变慢”的地理位置冲突问题。
1.  **境内线路（默认）**：配置为 **A 记录**，由 GitHub 脚本更新。保证国内用户走“高速通道”。
2.  **境外线路**：手动配置为 **A 记录**（或 CNAME），记录值指向 **`104.18.2.161`**（或 Cloudflare 官方 IP）。
3.  **效果**：
    *   国内用户 $\rightarrow$ 优选 IP。
    *   印尼用户 $\rightarrow$ 官方 Anycast IP $\rightarrow$ 自动分配最近的新加坡（SIN）或雅加达（CGK）节点。
    *   **统一域名**：两地用户访问的都是同一个 `cdn.hiyinni.com`。

---

### 第四阶段：强力缓存策略（极致提速）
**目标**：消灭 `REVALIDATED` 耗时，实现 0 毫秒二次加载，节省 S3 流量费。
1.  **Cache Rules**：创建规则匹配 `主机名 等于 cdn.hiyinni.com`。
2.  **设置边缘 TTL**：设置为 **1 个月**，并勾选 **“忽略源服务器标头”**。强制 Cloudflare 在节点内存里存住音频文件。
3.  **设置浏览器 TTL**：设置为 **1 个月**。让用户本地设备也存一份。
4.  **分层缓存 (Tiered Cache)**：开启 **Smart Tiered Cache**。通过 CF 内部超级节点回源，减少雅加达 S3 的压力。
5.  **安全避坑**：匹配条件必须精准使用 `cdn.` 子域名，防止误伤主站的 API 接口导致无法登录。

---

### 第五阶段：终极杀招——关闭 IPv6
**目标**：解决印尼本地运营商（Indihome/Telkomsel）因 IPv6 路由极差导致的“命中缓存依然 50s 延迟”问题。
1.  **痛点**：免费版 Cloudflare 后台锁死了 IPv6 开关，且浏览器会强制优先走不稳定的 IPv6 路径。
2.  **暴力破解**：使用 **Global API Key** 通过 `curl` 发起 PATCH 请求，强制将 Zone 的 IPv6 设置为 `off`。
    ```bash
    curl -X PATCH "https://api.cloudflare.com/client/v4/zones/区域ID/settings/ipv6" \
         -H "X-Auth-Email: 邮箱" \
         -H "X-Auth-Key: GlobalKey" \
         -H "Content-Type: application/json" \
         --data '{"value":"off"}'
    ```
3.  **结果**：浏览器被迫回退到稳定、成熟的 IPv4 线路。印尼延迟从 50s+ 瞬间降至 **20ms-50ms**。
