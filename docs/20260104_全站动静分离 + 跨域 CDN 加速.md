这份报告非常准确地捕捉到了你目前的瓶颈：**虽然你优化了“物流路线”（优选 IP），但你的“发货仓”（静态资源存储）依然在性能较弱的 Node.js 容器里。**

结合我们之前的所有配置，要彻底解决主域名慢的问题，最完美的优化方案就是实现 **“全站动静分离 + 跨域 CDN 加速”**。

以下是具体的优化路径：

### 1. 核心优化：修改 Nuxt 配置 (启用 `cdnURL`)
这是**性价比最高**的改动。你已经在 `cdn.hiyinni.com` 上搭建了极其完美的优选 IP + S3 回源 + 强力缓存。

*   **操作**：在 `apps/game/nuxt.config.ts` 中添加：
    ```typescript
    export default defineNuxtConfig({
      app: {
        // 核心改动：让所有打包后的 JS/CSS 资源路径自动指向你优化好的域名
        cdnURL: 'https://cdn.hiyinni.com/'
      }
    })
    ```
*   **效果**：
    *   用户访问 `hiyinni.com` 获取 HTML（这部分走 Tunnel，体积小，很快）。
    *   HTML 里的所有资源链接会自动变成 `https://cdn.hiyinni.com/_nuxt/entry.js`。
    *   **优势**：这些重资源将直接从 **S3 + 优选 IP** 链路下载，完全绕过你的 Docker 容器和 Node.js 进程。容器压力骤降，首屏加载速度会从“秒级”提升到“毫秒级”。

---

### 2. 资源同步：将 `_nuxt` 打包文件上传至 S3
既然 Nuxt 指向了 `cdnURL`，你需要在 CI/CD 流程中多加一步：
*   **动作**：Nuxt `build` 完成后，将 `.output/public/_nuxt/` 目录下的所有文件上传到你雅加达的 **AWS S3** 存储桶。
*   **配合**：确保你在 Cloudflare 里的 **Cloud Connector** 依然保持开启，它会自动帮你处理 S3 上的这些文件。

---

### 3. DNS 补完：主域名也上“优选 IP”
目前你只给 `cdn` 配了三网优选，主域名 `@` 还是 CNAME。这导致用户获取第一个 HTML 页面时可能还在绕路。

*   **操作**：修改 GitHub Secrets 里的 `SUB_DOMAINS`，改为 `cdn,@,www`。
*   **脚本逻辑**：让脚本每小时把这三个记录全部更新成**优选 IP**。
*   **结果**：用户输入 `hiyinni.com` 的瞬间，连接的就是最快的 Cloudflare 节点。

---

### 4. 解决“全栈同源”带来的缓存冲突
在现在的方案中，Node.js 容器既提供 API，又提供 HTML。
*   **风险**：如果 `hiyinni.com` 的 **Cache Rule** 写得太泛（比如“缓存整个域名”），会再次导致 API 登录不上的问题。
*   **优化建议**：
    *   **Cache Rule 1**（主域名）：仅针对 `hiyinni.com/` (主页) 设置较短缓存（如 5 分钟），**排除** `/api/*`。
    *   **Cache Rule 2**（CDN 域名）：针对 `cdn.hiyinni.com` 设置**永久缓存**（1个月）。

---

### 💡 优化后的最终链路：

1.  **用户浏览器** $\rightarrow$ 通过 **DNSPod 优选 IP**（境内）或 **104.18.2.161**（境外）秒连 Cloudflare。
2.  **获取 HTML** $\rightarrow$ Cloudflare 通过 **Tunnel** 穿透到你的 **Docker 容器**（只负责动态逻辑，负载极轻）。
3.  **获取 JS/CSS/音频** $\rightarrow$ 浏览器根据 `cdnURL` 指令，并发请求 `cdn.hiyinni.com`。
4.  **CDN 命中** $\rightarrow$ 流量直接在 **Cloudflare 边缘节点** 命中 `HIT`（从 S3 抓取后的强力缓存），不经过你的服务器，不经过 Tunnel。

### 总结建议：
你现在的方案是“能跑”，但资源全都挤在 Tunnel 里。
**请务必配置 Nuxt 的 `cdnURL` 并同步打包文件到 S3**。这样做完后，你主域名的 Network 瀑布图里，那几十个 Pending 的 JS 请求将全部变为绿色的 `HIT`，整个网站的打开体验会瞬间达到“雅加达本地应用”的水平。
