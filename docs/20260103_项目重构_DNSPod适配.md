# 项目重构：适配 DNSPod

## 背景
原项目 `BestDomain` 默认针对托管在 Cloudflare 的域名进行优选 IP 更新。
由于本项目的目标域名 `hiyinni.com` 托管在 **腾讯云 (DNSPod)**，原有的 Cloudflare API 逻辑无法使用。

因此，我们对项目进行了重构，将“大脑”从 Cloudflare 切换为 DNSPod。

## 变更内容

### 1. 核心脚本 (`bestdomain.py`)
-   **移除**：删除了所有 Cloudflare API 相关的代码。
-   **新增**：实现了 DNSPod API 的对接。
    -   获取 GitHub 提供的优选 Cloudflare IP 列表。
    -   通过 DNSPod API (`Record.List`, `Record.Modify`, `Record.Create`) 更新指定子域名的 A 记录。

### 2. 自动化工作流 (`.github/workflows/main.yml`)
-   更新了环境变量注入，现在依赖以下 4 个 Secrets：
    -   `DNSPOD_ID`
    -   `DNSPOD_TOKEN`
    -   `DOMAINS`
    -   `SUB_DOMAINS`

## 配置指南

为了让自动更新正常工作，请在 GitHub 仓库的 **Settings -> Secrets and variables -> Actions** 中配置以下变量：

| 变量名 | 必填 | 说明 | 示例 |
| :--- | :--- | :--- | :--- |
| `DNSPOD_ID` | 是 | 腾讯云 API ID | `123456` |
| `DNSPOD_TOKEN` | 是 | 腾讯云 API Token | `a1b2c3d4e5...` |
| `DOMAINS` | 是 | 根域名 | `hiyinni.com` |
| `SUB_DOMAINS` | 是 | 子域名（目前支持单个） | `cdn` |

## 运行逻辑
1.  脚本定时（或手动）触发。
2.  从 `ymyuuu/IPDB` 获取最新的优选 Cloudflare IP。
3.  通过 DNSPod API 检查 `SUB_DOMAINS.DOMAINS` (例如 `cdn.hiyinni.com`) 的记录。
4.  如果记录存在，更新为最新的优选 IP；如果不存在，自动创建。
